# 太平惠民和劑局方 卷之五 043 沈香鼈甲散（日本語訳）

## 原文の訳

沈香鼈甲散

男子・婦人の五労七傷で，気血が虚して損なわれ，腰と背がひきつり，手足が重く，すべての関節がだるく痛み，顔色が黒黄色く，肢体がだるく，動くと喘いで疲れ，胸膈がすっきりせず，咳嗽して痰涎があり，夜に異夢が多く，盗汗・失精し，臥すことを好んで力が少なく，肌肉が痩せやつれ，飲食を思わず，日に日に痩せ弱るもの，一切の労傷，諸虚百損を，みな治すことができる。

乾蠍（2銭半）　沈香（火に当てない）　人参（芦頭を去る）　木香（火に当てない）　巴戟（心を去る）　牛膝（芦頭を去り，酒に浸す）　黄耆（芦頭を去る）　白茯苓（焙る）　柴胡　荊芥（梗を去る）　半夏（生薑汁に二晩浸して炒る）　川当帰（芦頭を去る）　秦艽（芦頭を去る）各半両　附子（炮じて，皮と臍を去る）　肉桂（粗皮を去る）　鼈甲（酢に浸し，裙を去って黄色く炙る。各1両）　羌活　熟乾地黄（よく洗い，酒をふりかけて蒸し，焙る。各7銭半）　肉豆蔻（4個）

以上を細末にする。1回2銭を，水1盞，葱白2寸，生薑3片，棗2枚（裂く）で一緒に七分まで煎じ，空腹時，食前に〔服する〕。

## 解説

沈香鼈甲散の条（〔呉直閣増諸家名方〕）。五労七傷・気血の虚損による腰背のこわばり・手足の重さ・関節痛・顔の黒ずみ・倦怠・息切れ・咳・悪夢・盗汗・失精・痩せ・食欲不振，一切の労傷・諸虚百損に用いる。
- 人参・黄耆・茯苓・熟地黄・当帰で補い，附子・肉桂・巴戟・牛膝で腎を温め，鼈甲・柴胡・秦艽で虚熱を清め，沈香・木香・肉豆蔻で気をめぐらせ，乾蠍・荊芥・羌活・半夏を加える。
