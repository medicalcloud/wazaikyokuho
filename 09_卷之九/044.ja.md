# 太平惠民和劑局方 卷之九 044 詵詵丸（日本語訳）

## 原文の訳

詵詵丸

婦人の衝任が虚寒し，胎孕が成らず，あるいは多く流産するものを治す。

沢蘭葉　白朮（各1両半）　肉桂（粗皮を去る）　乾薑（炮じる。各半両）　熟地黄（洗って焙る）　当帰（洗って焙る。各2両）　川芎　石斛（酒に浸し，刻んで炒る）　白芍薬　牡丹皮（心を去る）　延胡索（各1両）

以上を細末にし，酢で煮た麺糊で梧桐子大の丸にする。1回50丸を，温酒で空腹時に服させる。

## 解説

詵詵丸の条（〔淳祐新添方〕）。衝任の虚寒による不妊・習慣流産に用いる。方名の「詵詵」は子が多いさま（『詩経』）。
- 四物湯（熟地黄・当帰・川芎・白芍薬）・白朮・石斛で補い，沢蘭・牡丹皮・延胡索で血をめぐらせ，肉桂・乾薑で温める。
